# 小屋主控电脑 (Shed Console Computer)

星露谷物语 Mod - 统筹整个小屋的小桶，按优先级自动投放作物、自动收取成品。

## 功能
- 自动投料/收成品，支持优先级设置
- 内置投料箱+成果箱，都是完整 36 格
- 支持小桶、木桶（陈酿）、罐头瓶
- 机器完成瞬间立刻自动收取（无需等扫描）
- 手动收酒后有 30 秒自动投料冷却，避免"收酒变放水果"

## 安装
1. 安装 SMAPI
2. 解压到 `Stardew Valley/Mods/`
3. 耕种 10 级获得配方，右键使用

## 使用
- 右键电脑打开主界面：
  - **投料优先级设置**：从投料箱的物品里选优先级，越靠前越先投
  - **小屋综述**：查看小桶总数 / 酿造中 / 可收取 / 空闲数量
  - **投料箱**：放原料（水果、蔬菜、咖啡豆 5 颗换 1 杯咖啡等）
  - **成果箱**：收成品
- 配置（可选，需 GMCM）：自动投料 / 自动收取 / 是否管木桶 / 是否管罐头瓶

## 开发
源码 + 本地测试工程（89 个用例，不依赖游戏运行）：
```
cd logic_test
dotnet build -c Release
dotnet bin/Release/net6.0/logic_test.dll
```
注意不要用 `dotnet run`（ModBuildConfig 会把启动目标设成游戏本体）。
